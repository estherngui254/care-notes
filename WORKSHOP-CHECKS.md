# Starter acceptance checks

Run these manually in the browser and record results in the participant workbook.

1. With no saved records, an empty state is shown.
2. Submitting an empty title shows an error and creates no record.
3. Adding a titled record displays it in the list.
4. Editing a record updates its title and details.
5. Deleting the last record restores the empty state.
6. Refreshing after adding a record keeps it in the list.
7. At narrow width, controls remain visible and record actions wrap below the content.
8. If storage is unavailable, the app shows a warning instead of crashing.

For customized projects, replace these checks with the project's acceptance criteria.
